What is GIT

發表於2026-09-28|更新於2026-10-27|Programming
|瀏覽量:

Git 係一個分散式版本控制系統（Distributed Version Control System），主要用嚟記錄程式碼嘅修改歷史。喺專業團隊或者企業級開發環境（例如 Big Tech、醫療科技公司、開源項目），用好 Git 唔單止可以防止 code 俾人亂改，仲可以實現多人高效協作、CI/CD 自動化測試同埋快速 rollback（版本回溯）。

1. 核心架構：程式碼嘅四個狀態

要真正理解 Git，首先要清楚你寫嘅 code 喺邊個位置：

  • Working Directory（工作區）： 你喺 VS Code 或 IDE 正在直接修改緊嘅本地檔案。
  • Staging Area / Index（暫存區）： 準備 commit 嘅「草稿區」，用嚟篩選同整理你想打包嘅修改。
  • Local Repository（本地倉庫）： 儲存喺你電腦（.git 資料夾）嘅完整版本歷史記錄。
  • Remote Repository（遠端倉庫）： 放在 GitHub / GitLab / Bitbucket 等伺服器，供整個 Team 共用嘅中央庫。

4. 業界的最佳實踐（Best Practices）

A. 規範化 Commit Message（Conventional Commits）

專業團隊通常遵循統一格式，方便生成 Changelog 同閱讀歷史：

  • feat: add user login API （新功能）
  • fix: resolve null pointer crash on signout （修復 Bug）
  • docs: update API setup steps in README （修改文件）
  • refactor: optimize SQL query performance （重構 code，無功能改變）
  • test: add unit tests for signal processing module （新增或修改測試）
